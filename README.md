# 🎮 Tic Tac Toe Game

A simple **Tic Tac Toe game** built using **HTML, CSS, and JavaScript**.  
This project is beginner-friendly and helps in understanding basic front-end concepts like DOM manipulation, event handling, and styling.

---

## 🚀 Features

- Two player game (Player X vs Player O)
- Interactive UI
  -Provinding Hints
- Displays winner or draw result
- Reset / Restart game option
- Clean and simple design

---

## 🛠️ Technologies Used

- **HTML** – Structure of the game
- **CSS** – Styling and layout
- **JavaScript** – Game logic and interactivity
